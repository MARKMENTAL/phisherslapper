Package cert

Leaf X.509 certificate fetching and CA/Browser Forum validation-level classification from policy OIDs. Source: internal/cert/cert.go.

Reserved policy OIDs: 2.23.140.1.1 (EV), 2.23.140.1.2.1 (DV), 2.23.140.1.2.2 (OV), 2.23.140.1.2.3 (IV). Priority order is EV > OV > IV > DV.

Details

 
type Details struct {
    Issuer    string    // Organization, or fallback issuer string
    Class     string    // EV, OV, IV, DV, or Unknown
    SANs      []string  // DNS SANs (CN fallback), empty when unavailable
    OIDs      []string  // raw policy OIDs found
    Subject   string
    IssuerStr string
    NotBefore time.Time
    NotAfter  time.Time
    HasCert   bool
}

Extracted leaf-certificate fields. Issuer prefers the Organization attribute and falls back to Common Name, then the full issuer string. SANs falls back to the subject Common Name.

Classify

 
func Classify(oids []string) string

Maps a set of policy OID strings to a validation class using the ordered priority table (EV first). Returns "Unknown" when none match.

cert.Classify([]string{"2.23.140.1.2.1"}) // => "DV"

InspectDomain

 
func InspectDomain(ctx context.Context, domain string, perCall time.Duration) (*Details, error)

Dials domain:443 with tls.Dialer (InsecureSkipVerify, since the peer is untrusted by definition) and returns the parsed leaf via FromLeaf. Transient failures are retried up to 3 times with a 1 second delay.

ParameterDescription
ctxParent context; the global 15 second budget.
domainAlready-normalized domain to dial.
perCallPer-attempt deadline (5 seconds in the CLI).

FromLeaf

 
func FromLeaf(leaf *x509.Certificate) *Details

Pure constructor: builds Details from an already-parsed leaf certificate. Preferred entry point for tests.

SANsString

 
func (d *Details) SANsString() string

Joins SANs with ", " for display, or returns "Unknown" when empty. Nil-receiver safe.
