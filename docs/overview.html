phisherslapper [v1.02]

Domain Impersonation and OSINT Triage Tool. Compares a known-legitimate domain (target) against a suspect domain using DNS resolution, X.509 TLS certificates, and RDAP registration data, then produces a deterministic risk score and verdict. Single static binary; standard library plus golang.org/x/sync only.

Build and Run

 
git clone https://github.com/MARKMENTAL/phisherslapper.git
cd phisherslapper
CGO_ENABLED=0 go build -ldflags="-s -w" -o phisherslapper ./cmd/phisherslapper
./phisherslapper jdsoft.com jdsoftcareers.com
go test ./...

Fetch Pipeline

Both domains are fetched concurrently with golang.org/x/sync/errgroup under a 15 second global deadline; each DNS, TLS, and RDAP call carries a 5 second deadline (adjustable with --timeout) and is retried up to 3 times. Total run time equals the slower of the two domains. Fail-closed errors name the underlying cause(s).

parse args --> DNS pre-flight (target + suspect, parallel; keeps per-path IPs, checks hosts file)
            --> fetch target   = RDAP + TLS + per-path TLS + ASN in parallel
            --> fetch suspect  = RDAP + TLS + per-path TLS + ASN in parallel
            --> fail-closed verify --> score --> render

Exit codes: 0 on success (including --scale and --help), 1 on bad flags, invalid domains, DNS failure, or failed data-quality verification.

DNS Consistency

Each domain is probed once by the system resolver plus pinned 1.1.1.1 and 8.8.8.8 servers, and the outcomes are reused downstream. Only state is compared, never raw addresses: system-dark/public-live suppression splits and NS delegation splits flag tampering (+50 on the suspect), while system-live/public-dark split-horizon shapes and target-side splits stay display-only NOTEs. CDN/GeoDNS address churn stays quiet. Inconclusive resolvers abstain; filtered resolvers are excluded by design. The pre-flight gate aborts on system failure with hijack-aware messaging.

Rogue Redirection

Beyond state comparison, the first live A record per side is retained and each endpoint is interrogated: the TLS identity served at the system-resolved IP is compared against the public-resolved IP (issuer, validation class, SANs, leaf fingerprint; SNI preserved). Origin autonomous systems for both IPs are attributed via Team Cymru (origin.asn.cymru.com TXT through the pinned resolver), and the OS hosts file is checked for static overrides. Divergent per-path TLS (+50), split origin AS (+30), and hosts-file overrides (+50) score on the suspect; target-side and inconclusive probes stay display-only. Raw addresses are never compared, so CDN/GeoDNS fronting stays quiet. Max total is 330.

Embedded Systems

The tool runs on embedded ARM devices (verified on a Miyoo Mini Plus), but minimal firmware often ships without a CA certificate store. DNS and certificate inspection still work there, while verified HTTPS (RDAP) fails; the fail-closed error names the cause (x509: certificate signed by unknown authority). Install ca-certificates and fix the clock where possible, otherwise use -k/--insecure as a last resort.
